30 秒上手

前置：在 open.mcd.cn/mcp 用手机号申请 MCP Token（免费，2 分钟）。
$ git clone https://github.com/xu9687/mcd-party-butler
$ cd mcd-party-butler && node setup-connector.mjs　# WorkBuddy 一键配置
$ node party.mjs plan --city 310100 --guests 6 --budget 150　# 直接出推荐

WorkBuddy 用户配置后直接对话「帮我看看上海周末有什么麦当劳派对」；CLI 用户零依赖，只要 Node ≥ 18。
